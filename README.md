# 忍者日常新事物整理

這個儲存庫用來整理日常筆記、靈感、待辦事項與參考連結。內容以 Markdown 保存，按日期分檔，方便持續記錄與回顧。

## 最近筆記

- [2025-10-25](2025-10-25.md)
- [2025-08-13](2025-08-13.md)
- [2025-08-01](2025-08-01.md)

其他日期的筆記也放在儲存庫根目錄，檔名格式為 `YYYY-MM-DD.md`。

## 儲存庫內容

| 檔案 | 說明 |
| --- | --- |
| `YYYY-MM-DD.md` | 依日期整理的日常紀錄、想法、待辦與連結 |
| [`prompt.md`](prompt.md) | 將日常紀錄整理成繁體中文摘要的提示詞 |
| [`pokemon_team.md`](pokemon_team.md) | Pokémon 隊伍相關筆記 |
| `README.md` | 儲存庫簡介與目前整理中的資源 |

## 新增日常筆記

1. 在根目錄新增以日期命名的 Markdown 檔案，例如 `2026-10-10.md`。
2. 將當天的想法、待辦事項、連結或其他紀錄寫入檔案。
3. 若有需要，將新筆記加入上方「最近筆記」清單。
